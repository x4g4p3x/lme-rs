# Fuzzing the formula pipeline

[Documentation](../docs/README.md) · [Contributor guide](../CONTRIBUTING.md)

The fuzz workspace uses cargo-fuzz and LLVM libFuzzer to exercise the real
formula parser and design-matrix pipeline with generated byte inputs.

## Prerequisites

- Nightly Rust, selected by [rust-toolchain.toml](rust-toolchain.toml).
- `cargo-fuzz`, installed with `cargo install cargo-fuzz`.
- Native build tools for the current platform.

## Targets

| Target | What it exercises |
|:-------|:------------------|
| `formula_parse` | Native lexer and typed formula parser |
| `formula_pipeline` | Successful parses followed by design-matrix construction on a synthetic DataFrame |

## Build and run

Start from the repository root, then remain in **`fuzz/`** for these commands:

```bash
cd fuzz
cargo fuzz build formula_parse
cargo fuzz build formula_pipeline
cargo fuzz run formula_parse corpus/formula_parse -- -runs=100000 -max_len=32768
cargo fuzz run formula_pipeline corpus/formula_parse -- -runs=50000 -max_len=32768
```

The checked-in corpus seeds both targets. Malformed formulas should return
errors rather than crash; fuzzing searches for violations of that expectation.

## Windows sanitizer failures

AddressSanitizer is the default. If a Windows fuzzer fails to launch with
`STATUS_DLL_NOT_FOUND`, check the ASAN runtime. An unsanitized local smoke run
is available from `fuzz/`:

```bash
cargo fuzz run formula_parse corpus/formula_parse --sanitizer none -- -runs=20000 -max_len=8192
```

This omits sanitizer coverage; report that limitation with the result.

## Reproduce a finding

Crashes and hangs are written to the ignored `fuzz/artifacts/<target>/`
directory. From `fuzz/`, replace the artifact path in this template:

```text
cargo fuzz run formula_parse artifacts/formula_parse/<artifact>
```

Reduce a finding to a regression test before fixing the parser when possible.

## Hosted checks

[The fuzz-smoke workflow](../.github/workflows/fuzz-smoke.yml) runs weekly and
on manual dispatch. A short smoke run is bounded coverage, not proof that
arbitrary inputs are safe.
